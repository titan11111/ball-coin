# 101-コイン集め

ボールを転がして、場にあるコインを全部集めるゲームです。

Unity `6000.3.26f1` のプロジェクトです。公開用のページは `docs/` に出します。圧縮なしの WebGL なので、GitHub Pages のまま携帯のブラウザで開けます。

## 遊び方

1. 「タップではじめる」を押す
2. 画面をドラッグしてボールを動かす（キーボードの矢印でも動く）
3. コインに触れると集まる
4. 全部集めたらクリア

下の「ポーズ」で止まります。「おと」で音を切ったり戻したりできます。

はじめのタップで、四国めたんが「ところで君は誰だ」「良い天気ですね。」と話します。

音声: VOICEVOX:四国めたん
